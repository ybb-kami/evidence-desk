# BM25 候选召回复测

检索在 E5 已返回候选、严格 BM25 和关键词两路均为空时，默认补一条 `bm25-recall` 排名，再与原 E5 排名做 RRF。其他路径保留既有行为。严格 `retrieve()` 继续使用原匹配阈值。排名数据保留原文和页块，宽松通道附 `retrieval_candidate: true`，用于提示这条出处还需核对。

宽松通道在覆盖率计算中去掉文档中未出现的普通查询词。主条件里明确写出的阿拉伯数字仍需在候选中出现，包括翻译漏掉的数字。长查询的候选至少要有两个匹配项，邻近词组与稀有词提高排序。短重合需要出现在局部，明确用「而不是」或 “rather than” 等词标出的排除说明不参与召回。

| 实测范围 | Top-1 | Top-3 | Top-8 |
|---|---:|---:|---:|
| 三份公开资料、六条开发题 | 4/6 → 4/6 | 4/6 → 4/6 | 4/6 → 5/6 |
| 独立 JMLR 文献、四条有依据的问题 | 2/4 → 4/4 | 3/4 → 4/4 | 4/4 → 4/4 |

六条开发题用来诊断与收窄通道。新进入第 5 位的是 DPR 的小批次负样本证据，原英文改写题中完全没有词面重合的正确段仍未命中。独立文献的长句从第 2 升到第 1，同词干扰例从第 5 升到第 1，英文含 OOV 噪声和中问英证的已有首位证据均保持。缺失数字负例询问 987664 词训练后的困惑度，宽松 BM25 返回空，E5 原排序保持。此次核验只检查候选排序与是否引入宽松数字候选。

两组比较对每条问题只计算一次真实 E5 排名，双方共享它与既有本机中译英结果。候选索引预热后每侧运行 5 次。排序中位数在开发组从 0.150 ms 到 0.423 ms，在独立组从 0.159 ms 到 0.567 ms。共享的 E5 暖查询时间为 14–73 ms，本机中译英历史运行另计。结果受样本、模型与本机 CPU 影响，独立组的四条正例来自同一文献。封存题和长书没有纳入此次比较。[逐题排名](results-bm25-recall.json)

将[六题资料](dev-cases.json)与测试脚本固定哈希的第 4 份 PDF 保存到同一目录。在运行工作台的 Python 环境从仓库根目录复测，有本地中英模型时沿用工作台的翻译环境变量。[测试脚本](../tests/check_bm25_recall.py)

```bash
python scanpdf/tests/check_bm25_recall.py --papers /path/to/pdfs \
  --e5 /path/to/verified-e5 --cache /path/to/benchmark-e5-cache \
  --report /path/to/new-bm25-recall-report.json
```
