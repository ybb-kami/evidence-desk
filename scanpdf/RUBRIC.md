## 比赛环境与交付

- §3.1 要求完整 Web 前端和 Agent 后端。评委能否在同一地址从新 PDF 走到可点开的原文，是部署验收的一项独立操作。
- §3.2 要求知识问答标注原文位置。复测应核对文件 SHA、物理页、段落或单元格，并检查原文能否支持结论。
- §3.3 商业 API 成本由参赛者承担。工作台可在本机运行。DeepSeek 由部署端从环境变量读取凭据，按次确认外发范围。
- §3.4 允许 AI 辅助开发，技术稿需交代个人参赛者与工具各自做了什么，以及 Prompt 和防护如何调优。应用内执行记录只展示工具、输入范围、执行结果与错误。
- §3.5 要求部署后兼容预置 `pdf/`。先传 v7 再传 v1、检查版本选择，导入 `1706.03762v1_img.pdf`，在第 8 页认表后问两列分数，再导入 500+ 页教材查尾章。每项保存部署 SHA、页码或原件哈希和实际结果。本机通过后仍需外部入口复验。
- 截止前由官网提交仓库、演示视频、技术文档和在线演示。可访问的公网 URL、独立评委权限和官网回执由相应交付方核实。既有监控与参赛服务应使用独立路由和存储。官网提交后如需修改应联系组委会。
