# 评审环境预置 PDF 目录

在仓库根目录运行预置命令。`--pdf-dir` 指向由部署者确认可信、解包后的本地 `pdf/` 目录。`--data` 须与工作台启动时使用的文库目录相同。可首次建库，也可对已有库增量导入。

```sh
# 适合同时演示长书、原版、改版、扫描、BERT 及 GPT-1 / GPT-3 的预置组合
python -m scanpdf.preload --data /path/to/library --pdf-dir /path/to/pdf --demo

# 逐个指定文件，保留其输入顺序
python -m scanpdf.preload --data /path/to/library --pdf-dir /path/to/pdf \
  --file 1706.03762v7.pdf --file 1706.03762v1.pdf

# 在同一目录加载 39 份原包镜像 PDF
python -m scanpdf.preload --data /path/to/library --pdf-dir /path/to/pdf --all

python scanpdf/workbench.py --data /path/to/library
```

`--all` 选取目录顶层 PDF，`--file` 只接受该目录下的文件名。原件保持原位。预置程序复用工作台入库实现，按原件 SHA-256 去重。相同内容换名仍保持库中已有名字与活动或归档状态。`--demo` 和 `--all` 先导入 v7 再导入 v1，两个版本都作为独立原件保存。可在工作台的版本与归档区按提示选择活动版本并恢复已归档版本。只需要一版时，可用 `--file` 明确选择。

命令返回 JSON，逐文件列出导入、已有活动文献、已有归档文献、拒绝或失败。损坏文件、容量拒绝和文件读取异常按文件记录，其他成功导入继续有效。退出码 0 表示选中项都已导入或已有，1 表示至少一项失败或被拒绝，2 表示启动、选择或数据库初始化出现错误。修正输入或库路径后可用同一条命令重跑。库正在使用时，SQLite 保持提交一致性，短时写入争用可按报告重跑。

报告列出每份文献的物理页数、可索引片段及无索引文字的页。`pending_textless_pages` 是尚未识别或未记录识别结果的无文字页。`recognized_textless_pages` 是已有识别记录但仍无索引文字的页。实际扫描件可按需在工作台按物理页识别。空白页也可能出现在无文字页列表。

## 空库预算与后续上传

文库的默认限制为合计 50 份文献、128 MiB 原件字节、12,582,912 个序列化索引字符。每个 PDF 原件最多 24 MiB、650 页、200 万提取字符、12,000 段。归档文献纳入文库容量，扫描结果有独立的 12 MiB 压缩缓存预算。容量报告单列实际使用及余量。`max_next_upload_original_bytes` 给出字节层面当前可接收的上界。下一个文件还须通过页数和文本索引限制，其他进程的新导入也会改变该余量。

39 份镜像原件合计 131,842,159 字节。空库全部预置后只余 2,375,569 字节的原件预算（约 2.27 MiB）和 11 个文献名额。预置示范组合可为后续上传留出更多容量，完整 39 份适合固定验收文库。可为完整验收指定独立的 `--data` 目录。SQLite 文件及临时日志另有文件系统开销。

## 原件与物理页复测

使用本机已解包的镜像资料和固定清单。验收在临时文库内运行，重用现有 HTTP、长书和扫描参照数据。实测内存使用 Linux `/proc` 及子进程资源计数。扫描需本机安装 Tesseract 英文模型。

```sh
python -m unittest -v scanpdf.preload.test_load

python -m scanpdf.preload.verify /path/to/pdf /path/to/manifest.json
```

`verify` 逐份核对固定镜像清单中的 39 个文件名、字节长度和 SHA-256，运行首次预置、重跑、演示组合、坏件修复与归档别名测试。并发阶段同时读取两次原件和原页，以及上传两份独立文档，最多 4 个客户端。随后检查所有预置项和新上传仍可读，并实测超出剩余字节上界 1 字节的拒绝行为。

长书核对检索命中物理第 440、476 和 541 页，PDF 页标签分别为 426、462 和 527，并校验原页链接及原块。扫描件按需识别物理第 8 页，依据既有独立参考坐标核对表 2 BLEU 的 EN-DE 和 EN-FR 两列，验证单元格分离和原页链接。验收所用固定镜像由公开仓库提供，出处和组委会原始哈希的核验边界见样本记录。[39 份资料的固定镜像](https://github.com/CuiMiles/ResearchTrace/tree/52d11950da4f3da1dcb830d6212665eb89c0394f/evals/pdfs/科研小助手) · [固定 manifest.json](https://raw.githubusercontent.com/CuiMiles/ResearchTrace/52d11950da4f3da1dcb830d6212665eb89c0394f/evals/pdfs/%E7%A7%91%E7%A0%94%E5%B0%8F%E5%8A%A9%E6%89%8B/manifest.json) · [扫描件来源及哈希](../SAMPLE_REVIEW.md)
