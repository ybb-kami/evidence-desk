## 从一个提问走到原文

1. 上传后服务以 PDF 字节的 SHA-256 标识版本。页码从 1 开始。字符偏移在该版本、物理页和文本块内解释，扫描页还保存坐标和 OCR 方法。
2. 问题随选中的文献身份提交。服务先核结构化表格和明确的论文字段，再对其余问题做 BM25、跨语向量和排名融合。库内另一篇相似论文不能替代选定的版本。
3. MobileBERT 提议原文中的字符范围。Qwen 在本机读取编号短摘录，按 JSON Schema 提供回答和引文。服务端重新切取原文、核数字、检查是否缺乏直接证据。读者可点页段或单元格对照原页。
4. 扫描解析把检测框、转录、单元格、公式候选分开保存。裁切框自身不含足以发表的 LaTeX。比较两个版本的数值时，要核原表、单位和实验条件才计算差值。

## Prompt 调优记录

| 观察 | 设计调整 | 验证与限制 |
|---|---|---|
| 只要求模型“附引文”时，早期自由文本拒答曾附无效编号。 | 把资料段编号；本机模型须返回 `status/answer/source/quote`。LLM 无法指定文件、物理页或偏移，服务端从文库求出。 | 两个有依据问题和设备序列号缺失问题有独立新 PDF 浏览器回放。引文不存在、负号变化和未知编号有回归测试。 |
| SQuAD v1 系列读者可以从缺答案的文本中照样挑出跨度。 | 对抽取结果检查边界、计量对象、相近分数的冲突，再决定展示为抽取候选还是作答。 | 双源给出不同数值时保留原文条件。抽取分数不能单独证明问题可答。 |
| 所问实验条件与引文可能只共享若干关键词；模型甚至能用同页另一处数值来回答。 | Prompt 明确要求所引原句涵盖对象、条件和读数。结构、逐字引文、带符号数字和条件匹配另设独立程序检验。 | 用户仍需判断引文是否支持整句。拒答、超时、没有命中和答错字段在评估中分别计数。 |
| 页内图片、论文文字和题录可能含有写给模型的指令。 | 论文文本以引用材料输入。本地问答不执行论文中的文字。远程草稿只在明确同意后发送选定摘录；服务端限定工具、文献范围和参数。 | 外部调用是否成功必须有对应运行记录。模型密钥由运行环境注入，页面和源代码不展示密钥。 |
