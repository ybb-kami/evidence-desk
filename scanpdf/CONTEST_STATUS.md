### 六项功能

| 模块 | 已运行的路径及结果 | 剩余差距 |
|---|---|---|
| 1. PDF 管理和解析 | 39 份资料包 PDF 在同一临时文库通过 HTTP 导入；v7→改名 v1 可提示保留新版并可恢复；541 页教材末页可查。扫描页经浏览器整篇识别、可暂停继续，15 页产生 233 个文本块。4 张表均定位，2 张恢复行列；三条编号公式均可按原图框核对 | 复杂公式仅定位；表 2、3 未恢复行列。作者机构、图表等细粒度字段尚未全面核验 |
| 2. 知识问答 | 本地中英词汇和符号归一化可找到训练硬件、优化器、参考文献的英文原文；可并排比较两篇的证据。DeepSeek 核选有逐字引用校验和无证据处理 | 本环境未绑定 DeepSeek 凭据，未实测线上生成；陌生问题、多轮指代与跨篇综合问答缺少独立质量评测 |
| 3. 阅读翻译 | 原件页、目录、数字引文往返；CPU 本地 OPUS-MT/CTranslate2 英中及中英已实际推理。可选区、逐段、整页或连续至末页，原译文对齐，能查看对应原图。实测保护整段公式和等宽代码 | 专业术语可能误译。两页连续翻译已测，整本教材的全文翻译质量及双语排版导出待验 |
| 4. 公开发现与推荐 | 有题录检索、手动 arXiv 分类更新、反馈排序及按 arXiv ID 下载入库路径。机构网络拦截时能提示失败，未写入成功记录 | 当前环境未能从 arXiv 取回真实 PDF；参考文献自动下钻、定期刷新、推荐效果尚未闭环 |
| 5. 图谱及综述 | 39 份材料形成 38 个作品节点、75 条局部引用边，全部回查到对应 PDF 页块。提要列出有来源的边与未来工作候选；可筛选有日期、有引用及正文主题重叠的后续材料供人工复核 | 本批资料按保守条件筛出 0 条后续候选。缺开放域新工作核查与模型综合综述质量评估，局部 PageRank 仅反映本库 |
| 6. 写作及图表 | 主题和选定证据可导出 Markdown 框架；CSV 能生成表、折线、柱状图、图注与行映射；可把作者填写的多条步骤链转为 Graphviz DOT，真实浏览器下载与 Graphviz 渲染已测。本地中译英可处理中文 PDF 摘要选区 | 缺研究综述自动成稿、三维雷达图及独立写作质量评审 |
