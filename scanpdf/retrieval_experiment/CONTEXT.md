## 工作台使用的选择器

当前工作树的 `select_excerpts` 是工作台本地模型和 Flash 引用生成的共同默认选择器。真实问答传可用的中译英和经过筛选的抽取读者提示。条件、数值和原文引句的下游校验继续生效。普通摘录先覆盖不同候选块的互补线索，在预算允许时补相邻原句。问题明确限定图、表、公式或章节时，含独立数值的补充邻句须来自包含对应来源标号的候选块。原文始终使用原块内连续区间。两个回放口径均省略抽取读者提示，直接度量生成之前的证据可见性。[默认选择器](../evidence_context.py) · [本地生成接线](../local_generation.py) · [Flash 引用生成](../flash_transport.py)

## 复跑

按既有 README 准备三份原件和本机 E5、OPUS 权重。在项目根目录运行如下命令。添加 `--translated-query` 可对新旧两边使用可用中文译文。添加 `--include-cases` 可定位逐题候选和摘录区间。[论文准备](README.md) · [配对回放程序](compare_context.py)

```sh
PYTHONPATH=.:scanpdf EVIDENCE_TRANSLATION_MODELS=/path/to/models \
  python -m retrieval_experiment.compare_context --pdfs /path/to/pdfs --expect-translation
```
