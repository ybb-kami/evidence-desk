# 单篇多字段题怎样计答

在工作台「证据追问」中，两三个明确独立的问句可以分别检索。当原文直接给出一个数值且计量对象、条件和单位相符，系统可直接引用原句。其他题可使用本地抽取和生成。多个可能条件同时成立时展示缺口。每个字段保存自己的文件指纹、物理页和文本块。字段不全时，界面明确列出未答部分。

生成式回答会核对逐字引文、数值和显式计量单位。PDF 的折行、连字字形与空白差异可映回原件字符区间，出现多种可能位置时不把某一处当成唯一出处。即使全部机器检查通过，仍需读者复核有关实验对象与语义关系。

在新建的两页声学测试报告上，用 Chromium 从问答表单提交三题。第一题同时询问加热时的采样频率和验证集样本数，输出 92 Hz（页 1）和 31（页 2）。第二题省略加热与冷却条件，提示需要指定条件。第三题同时问冷却频率与仪器序列号，只确认 67 Hz，并指出缺少序列号。所有支持句按 API 回传的偏移在对应原始文本块中重新切取。新开发样例检验预期行为，泛化质量另看封存题。[浏览器结果](results/new-acoustic-fields.json) · [封存题](BLIND.md)
