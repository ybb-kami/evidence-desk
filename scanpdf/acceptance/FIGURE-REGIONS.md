# 扫描图版定位验收

`scanpdf.figures` 是扫描图版的独立命令。结果给出源 PDF 的 SHA-256、1 起算的物理页、OCR 图注及其行号和坐标，以及关联图框与可选原图 PNG。坐标以渲染后的旋转可见页左上角为原点，同时保存像素和 PDF 点。独立的 `pN-fN` 编号供本次图版输出使用。原扫描管线的表格与公式 `pN-rN` 可以继续按原入口回读。

算法在图注上方查找图版。先从 Tesseract 文本定位图注，依据行距、对齐和 OCR 分段聚合换行。再用文字框遮去 OCR 字词，通过水平与垂直的连续笔画定位图形，回到原图恢复临近的边缘文字。候选触及表格检测框、包含连续正文、与同页已有图框重叠或只覆盖宽图中一小片笔画时，保留确认到的图注和未定原因。正文对某个图号的句内引用不会建立图框。

三处通过区域分别检查原页中的手选视觉坐标、图注文字和边界、表格交叠，以及导出的 PNG 与原页同坐标截取逐像素一致。固定几页的检查没有估计全库召回率或精度。当前对图注在上、竖排或跨页组合图没有建立通用规则。OCR 图注可能误字或缺行，图内语义、关系和曲线数据均未识别。该模块在本机命令行运行。

```sh
# 仓库根目录。建议 Python 3.11+、Tesseract 5.5.0，并安装 eng 语言数据。
python -m pip install -r scanpdf/requirements.txt

# 使用本地解开的公告包。脚本核验这三份 PDF 的固定哈希。
python scanpdf/acceptance/figure_regions.py --pdf-dir /path/to/contest-pdf --output /tmp/figure-replay

# 独立扫描命令。输出及裁图文件名应可新建。
PYTHONPATH=scanpdf python -m scanpdf.figures /path/to/contest-pdf/1706.03762v1_img.pdf \
  --pages 3,4,8,13 --output /tmp/attention-figures.json --crops /tmp/attention-figures
```

公告包可按[资料包说明](README.md)下载。复跑目录内有 `results.json`、两个有出处映射的单页光栅件和三个原图裁片。本次记录包含软件版本、图框、完整源指纹、原物理页及裁片哈希。[机器验收记录](results/scanned-figures.json)
