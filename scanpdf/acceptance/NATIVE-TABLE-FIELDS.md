# 原生 PDF 多字段表格问答验收

固定八个有据问题和两个需说明缺口的问题，再运行旧解析路径。数值和原文文字从各 PDF 的物理表格核对。五份论文原件与一个独立生成的无表号、无分隔线双列 PDF 用于这一轮验收。旧路径在八个支持问题中没有答全。新路径完整回答八个问题，两个缺口保留。

| 来源 | 覆盖内容 | 核对结果 |
|---|---|---|
| GLM-130B，物理页 48 表 11 | 两列配置表，含中文问题及无表号的英文问题 | `adam`、`nccl`、`rotary` 与层数 70。另一问得到全局批量 4224、`True` 与序列长度 2048。不存在的校准字段留缺 |
| FlashAttention，物理页 7 表 1 | 单个横向分隔线，带单位和不确定性的原文值 | `20.0 ± 1.5 minutes` 和 `17.4 ± 1.4 minutes` |
| Vision Transformer，物理页 13 表 3 | 同名模型按训练数据集区分，同时查多个字段 | ImageNet-21k 给出 90、`linear`、0.03 与 0.1。两个数据集的轮数分别为 7 和 90。缺少数据集的问法保留歧义 |
| LoRA，物理页 20 表 11 | DART 专属值和多个任务共列的设置 | 丢弃概率 0.0、批量 8、预热步数 500、调度 `Linear`。后面三项保留原表跨列范围 |
| BLOOM，物理页 21 表 3 | 模型在列，字段在行，原分隔线未覆盖完整表格 | 层数 30、隐藏维度 4096、注意力头数 32 |
| 独立双列样表，物理页 1 | 无表号、无分隔线，精确短文本和电压 | `MICA-9`、`Linear drive` 与 `18 V` |

工作台通过 `/api/followup` 返回 25 个被引用的单元格。用 `/api/source` 从原件重算所有坐标，25 个原文值和矩形均一致。自存的引用使用各 PDF 的 SHA-256、物理页、区域、行列及坐标。

原生恢复使用版面词框和表题、列标题、对齐重复或显式分隔线。跨列共享值要求横向位置重复且与单列中心有明显区分。数值与带单位的报告文本按原样转述，能确定的字段可和缺口一同展示。复杂或重叠版面的支持范围取决于可验证的物理结构。派生差值只处理同列同单位的两个标量。

```sh
run_dir=$(mktemp -d)
python scanpdf/acceptance/native_table_fields.py --pdf-dir /path/to/contest-pdf --output "$run_dir/result.json"
```
