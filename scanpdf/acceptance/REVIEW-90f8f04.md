## 本地运行和后续接入

在新的工作目录检出上述分支。运行需要 Python 3.12、对应 Python 依赖、Tesseract 和英文语言包。多语 E5 和 OPUS 要安装或挂载固定模型，浏览器验收另需 Playwright 和 Chromium。PDF 文库使用独立数据目录。复跑时请使用实际预置文件目录。[运行与依赖](../DEEPSEEK-JUDGE.md) · [容器](../container/README.md) · [CSV 渲染](CSV-TRENDS.md)

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r scanpdf/requirements-rag.txt
.venv/bin/python scanpdf/workbench.py --data ../evidence-judge-data --port 8765
```

已授权的部署方可通过环境变量配置模型、费率和共享持久预算账本，启动时加入 `--enable-deepseek`。保留已约定的 0.71 美元上限。评委工作台将本地生成器显式关闭；旧版 Qwen 用于历史试验。现行问答的生成服务选择 DeepSeek Flash，查 PDF 原文页则使用 BM25 与 E5。此工作台实例没有凭据，验收程序实际返回 `server_model_not_configured`，模型和搜索请求均为 0。使用部署方已有的评委进程才能核对真实 Flash 与 Search。运行以下命令会通过网页真实上传和提问，并明确区分供应商返回、引文核对失败及本地处理。该操作由持有已配置服务的一方执行。

```sh
python scanpdf/acceptance/judging_browser_live.py --url http://127.0.0.1:8765 --with-search
```

真实评委地址需独立路由到科研工作台，使用独立文库、进程及账本。供评委的首页应直接展示科研助手。公网测试、官网提交回执尚由交付线程核实。仓库中已有技术 PDF 和普通话视频，录制版与本轮源码时间不同；本轮验收附件注明了各自的版本。
