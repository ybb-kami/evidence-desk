# 公开文献发现与获取

扫描工作台的 `/download` 支持按公开题名或参考文献信息查询 Crossref，以及按公开 arXiv 编号下载 PDF。两项操作各自需要逐次确认。可输入带版本的编号，例如 `1706.03762v1`，也可接受 arXiv 对不带版本的编号返回的文件。查询书目后可以查看 DOI 或复制书目记录中的 arXiv 编号。

下载仅从固定 HTTPS 地址 `https://arxiv.org/pdf/` 请求输入的编号。响应大小上限为 24 MiB，总请求限时 18 秒。PDF 导入当前文库，按原件 SHA-256 去重，已归档重复项保留其归档状态。下载记录包含请求编号、公开来源地址、UTC 下载时间及 SHA-256。服务端不会将题名、查询历史或文库内容随 PDF 请求发送给 arXiv。

若运行环境无法访问 arXiv，页面显示连接失败，可通过工作台的 PDF 导入手动选择已有文件。应用不会自动读取共享目录里的文件。Crossref 返回记录的位置是书目线索，全文获取需要公开 arXiv 编号。
