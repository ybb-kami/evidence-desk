4B 补齐了一条双字段答案，也有一条歧义题通过核验后输出了未经问题限定的值。此次样本不足以支持切换默认。用现有约束扩大 4B 的盲测前，需先处理不同条件共享同一页块时的核验缺口。

延迟从固定输入的 `answer()` 调用开始计时，包含本机 HTTP、生成和冻结核验，模型启动另计。1.7B 保留原 4 线程和原缓存设定。4B 使用 3 个生成线程和 3 个批处理线程、关闭轮询、缓存上限 128 MiB。两端使用 4096 上下文和同一版 llama.cpp b7940。4B 复测进程观察到约 4.7–4.8 GiB 驻留内存。这里记录的是这两种实际配置的耗时，线程和提示词缓存会影响延迟。

## 复现

按[安装说明](README.md)分别启动两端。准备上方题目文件列出的四份 PDF，以及冻结版本的源码目录。脚本逐项校验 PDF 和生成相关源码哈希。

```bash
python scanpdf/local_llm/compare_instruct.py --source-tree /path/to/c94c628 \
  --papers /path/to/pdfs --arm 1.7b --report response-1.7b.json
python scanpdf/local_llm/compare_instruct.py --source-tree /path/to/c94c628 \
  --papers /path/to/pdfs --arm 4b-instruct-2507 --report response-4b.json
```

用顺序命令执行，待前一轮模型响应结束后再运行后一轮。若 1.7B 由安装说明中的默认文件名启动，请在第一条命令加 `--model Qwen3-1.7B-Q4_K_M.gguf`。
