# 证据台 · DeepSeek 联调候选

参赛团队：个人参赛；公开预览不展示可识别身份信息。

此目录是候选接线，不是已经上线的服务。运行环境：Linux、Python 3.12（标准库 SQLite 与 TLS）；原件问答需已有证据台主程序及其锁定 PyMuPDF 和表格解析依赖。凭据仅由部署方在进程运行时配置，不应写入仓库或浏览器。

`python -m unittest` 检验限额、重启和并发；`python grouped_http_smoke.py` 覆盖双席的搜索和抓取；`python three_http.py --app /path/to/app.py --docs /path/to/attention.pdf /path/to/bert.pdf` 检验选择两份原件、展示发送内容、单次确认，以及同一账本下的三类模拟请求。模拟测试不会读取密钥或产生 API 费用。

线上只允许一个事先配置的持久账本和固定供应商。最多100组，按峰价每次模型保守预扣完整2^20输入窗口加512输出（0.3151872美元），工具各0.00075美元；一整组合计0.3166872美元，应用实际提交的官方模板编码不超过16384 tokens，旧政策总额为 0.71 美元。四席评委补丁支持将同一原账本升级为累计 20 元人民币等值，当前汇率快照下为累计 2.50 美元，每次扣减均计入已有预留。工具只发另行确认的公开查询或选定学术 URL，模型只发已选文献在预览中列出的文字。网页内容不冒充已交叉核验的 PDF 原文。旧 discovery_tickets.Ledger 仅为历史单元测试夹具；不得用它配置付费服务。

四席入口、同账本原位迁移、隔离代理、免费复跑和旧版浏览器脚本的接口范围见[本次交接](FOUR-SEAT-HANDOFF.md)。

## 单篇问答

导入公开 PDF 后，在「单篇问答与跨文献综述」选择一篇，输入问题并点「预览单篇问答」。核对原页摘录和本次完整请求后，勾选同意并点「发送并生成待审回答」。每条草稿带原件页码和文本块链接，是否支持主张仍需逐条核对。缺少可核实摘录时不生成发送令牌。位于参考文献标题之后的段落及可识别的参考条目不会用于单篇回答。选择 2 至 6 篇仍可生成跨文献综述。

两种模式共用同一对接口和预算。`POST /api/synthesis/preview` 接收 `{"ids":["<本席 PDF SHA-256>"],"query":"..."}`，`POST /api/synthesis/confirm` 接收 `{"token":"...","consent":true}`。训练硬件类单篇问题在首次本地查找无命中时可用等义检索词再查一次，发出的请求保留用户原问题。预览令牌绑定本席、选中文献、问题、发送字节和原文位置，确认前会重核这些内容。同一预览仅能确认一次。本地夹具显示「离线模拟」，测试不会向 DeepSeek 发送请求。

在安装 PyMuPDF 和固定 `tokenizers==0.22.1` 的环境中，从仓库根目录运行以下回环验收。

```sh
python -m unittest discover -s integration/deepseek-discovery -p test_single_paper_http.py -v
```

对于两笔库外历史请求，请先核对供应商 usage、账单或实际请求上界，再按[首次启用说明](OPENING-RESERVE.md)接入同一份预算。
