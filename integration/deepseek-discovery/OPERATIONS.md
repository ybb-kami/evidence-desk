# 部署与回滚：仅供拥有服务器权限的维护者

1. 先查实际网关进程、工作目录、unit、反代、账本唯一持久卷和活动会话。不要输出环境变量、凭据、Cookie、用户输入或文献。当前候选并非可覆盖安装包，不能替换现网目录；不得在第二台机器同时启用同一额度。
2. 在新版本专属私有目录解压；仅 Linux x86_64 / CPython 3.9+ ABI wheel，实测 Python 3.12。沿用已验证的隔离主程序/解析依赖，另建 venv，执行 python -m pip install --no-index --no-deps wheel/*.whl。python -m unittest；公开 PDF 实测依赖单独准备原件。默认所有测试只模拟供应商，不能代替真实回执。
3. 单运维者先停旧的收费发送入口（不要杀现有阅读席位），确认无其他收费通道。用 SQLite 在线备份或停写后备份到私有位置。禁止删除、覆盖、替换或重建既有账本。若仅旧工具记录且指纹完全匹配，可由维护者明确调用 GroupBudget(...).migrate_tool_only() 原位事务升级；如果检测到旧模型记录，一律拒启先核账。若从未创建总账，必须在所有曾经执行的主机确认没有它，再由指定维护者在目标机唯一持久路径显式 provision() 一次；默认工厂不会代为创建。
4. 四席共用单个网关实例。将 operator_runtime.runtime(config,key) 返回值作为 gateway.serve(..., **bridges) 的桥配置；由操作系统密钥设施向网关进程提供key，不放入argv、前端、配置文件、仓库和回执。不要同时配置旧模型入口。config严格只含 path,approval_sha,price_sha,verified_epoch,expiry_epoch,seat_groups，必须是真实授权/定价快照的哈希，过期闭锁，不能换空账。
5. 在仅回环的独立实例先验只读/模拟交互；真实付费必须走唯一账本，使用公开 PDF 和公开查询。从浏览器预览并确认已列的摘录/目的地，搜索和抓取各另确认。逐次查供应商状态、usage、PDF引用回链及账本扣额；缺凭据/认证/来源/断线停止，未知结果不重试。只记录脱敏回执。通过后、窗口无活跃访客时再考虑已有8443代理切换；不可因临时预览抢占或销毁原有用户席位。
6. 回滚：停止新请求，待在途完成；将已有代理恢复到此前已验证进程。若旧进程无法用同一新版账本，保持旧付费模型全关。不要回滚或还原账本快照来恢复额度。不要向不可信网址转发。
