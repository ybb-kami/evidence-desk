# 证据台 v0.2 · Evidence Desk

> 最新验收与功能请先读 [v0.4 状态](STATUS.md)；下文包括旧版本的入门与历史边界。
把“这句话到底写在哪一页？”变成一次可核对的操作。面向单人本机的 PDF 文献检索工作台：导入材料、搜索关键词、并排比较两条原文、点页码回看 PDF。默认不出网，无需账号或模型密钥。新增按篇证据对照、本地引用关系与可选 Crossref 公开题录发现。[三分钟演示脚本及可复核样例](DEMO.md)。它是竞赛原型，不是已完成全部赛题功能的科研 Agent。

## 三分钟试用

需要 Python 3.10 或更新版本、可安装 PyMuPDF 的桌面电脑，以及浏览器。首次安装依赖需访问 Python 包源；运行本地检索不需联网。打开终端，进入解压后的本目录：

**Windows：**
```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```
**macOS / Linux：**
```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

1. 浏览器访问 **http://127.0.0.1:8765**。这是本机入口，不是在线演示网址。若端口冲突，运行时加 `--port 8766`，并打开相应地址。
2. 在界面下载示例并导入，或直接导入包内 `sample.pdf`。选择“填入示例关键词”，检索 `verify page numbering`，打开 **第 2 页**核对内容。这是原创操作说明，不是研究成果。
3. 尝试 `zzzxqz`，应提示没有检索到证据；把同一 PDF 改名再导入，不会产生第二份记录。不同版不会被自动删除。可对两条结果使用“加入对照”。
4. 自有授权公开文献：用原文里的术语查询，例如在 *Attention Is All You Need* 中搜索 `P100 GPUs`。中文输入不会自动翻译为英文。
5. 终端按 Ctrl+C 停止。本地文库在 `data/library.sqlite`。下次用同一数据目录即可恢复；`--data <另一个目录>` 建立独立的新文库。请自行保管含原 PDF 的数据库。

**可选 DeepSeek**：只在你通过自己的私密环境变量配置 `DEEPSEEK_API_KEY` 后，以 `app.py --enable-deepseek` 启动，且每次在界面同意发送查询和证据摘录，才会请求官方 DeepSeek 服务（可能计费）。未确认时不会调用；没有匹配时也不会发送。线上核选只返回本地能逐字对照的引用，不生成未经核查的事实。详见 [服务与隐私](DEEPSEEK.md)。本交付没有使用真实 key 联调；合约测试不代表线上服务可用。不要把 key 粘到聊天、源码或仓库里。

**可选英文 OCR**：Linux / macOS 安装本地 Tesseract 英语语言包后，执行 `python ocr_local.py input.pdf input.ocr.pdf`，再手动导入衍生副本。最多 10 页纯扫描件；页序保留、不会覆盖原件，识别结果必须对照原图。见 [OCR 说明](OCR.md)。

## 已实现与边界

| 能力 | 本版能做什么 | 不承诺什么 |
|---|---|---|
| 文献导入 | 多选；按物理页/文本块取原文，保留可得的页标签；保存原件 | 不把提取到的纯文本说成表格、LaTeX 或图表结构 |
| 去重 | 文件字节、规范化原文、五词片段相似度；匹配正文和首页 arXiv 标记时可提示版本顺序 | 不仅按文件名、不自动合并两个不同文件；近似阈值不是同一版本的证明 |
| 找证据 | 原文词法检索、指定文献、页码链接、最多两条并排；无匹配时明确返回空 | 不是通用问答，不自动跨语检索；没找到不等于文中没写。PDF 查看器是否跳页取决于浏览器 |
| 模型核选 | 可选的 DeepSeek 摘录选择，返回时逐字验证引用，页码由本地确定 | 引文真实不等于与问题相关或支持某项结论；没有长期自主规划或跨文科学推理 |
| 阅读与来源 | PDF 原页和命中文本；图片页明确标记无可检索文本 | 主界面不会自动 OCR、翻译或识别数学公式；引用图谱仅基于本地文库 |
| 规模 | 单份最多 24 MiB、650 页、200 万文本字符、1.2 万片段；本地库最多 50 篇，总 PDF 不超过 128 MiB，序列化索引上限 1200 万余字符 | 公开作者版 541 页书籍已实测；不能据此认定与组委会文件逐字节相同 |
| 权限 | 只监听回环地址，浏览器同源操作，数据保存在本机；不使用外部前端资源 | 不面向公网、无多用户鉴权、无多租户隔离，不要转发端口或直接部署为公用服务 |

## 核查及开发记录

- [实际验收和限制](QA.md)；[赛事功能差距与下一步](COMPETITION.md)；[开发决策及真实交互摘记](DEVELOPMENT.md)。
- 完整回归（无需服务预先启动）：在已安装依赖的虚拟环境中执行 `python -m unittest discover -v`。真实服务验收使用临时数据库。
- 结构：`index.html` 是无构建依赖的界面；`app.py` 处理本机 HTTP 和 SQLite；`engine.py` 提取、检索和匹配；`provider.py` 是独立的可选远端核选器；`make_sample.py` 仅用于重新制作示例，不是运行所需。
- 打包源码只包含已追踪文件。随包的 `history.bundle` 保存实际开发提交，可在解压目录外执行 `git clone /path/to/history.bundle evidence-desk-history`。历史记录中没有个人密钥、付费账户或真实用户文献。

**v0.2 数据与网络边界。** 旧库可继续检索；旧文献可能缺少新图谱需要的标题信息。如需完整复现图谱，请在新 `--data` 目录导入原件，无需删除旧库。Crossref 仅在本次主动确认后发送填写的公开检索词；不发送已导入的 PDF。题录不代表已获全文或已验证研究结论。图谱仅识别本地标题、DOI 或 arXiv 标识能消歧的参考条目，未连线不等于未引用。
