# 在线演示的隔离方案（尚未部署）
不要把 app.py 改为监听 0.0.0.0，也不要用反向代理伪造 Host 公开本机工作台。它不是多用户服务。
建议先提供单独的**静态只读**演示：全新目录内只放已许可的原创示例 PDF、静态页面与预先运行得到的公开示例结果；不挂载开发目录、Git、环境变量、数据库、上传、解析器、远程模型、arXiv/Crossref 接口。清楚标为预计算只读体验，不冒充完整系统。若赛事强制任意输入/在线 Agent，则这种演示不足以满足资格要求。
正式上线需由所有者明确授权组织、主机/域名、费用及展示范围；HTTPS、访问控制、限速、最少日志、到期下线由托管方落实。从外部网络用真实浏览器回归可用性、PDF 原页、越权隔离、禁止上传和模型、错误响应；记录 URL 和录像后方可宣称在线。
若必须让评委实时上传：单独进程/系统账号、认证、按评委隔离存储、每户大小/CPU/时间/请求及并发上限、不可出网的 PDF 解析沙箱、到期清除约定及服务端隐私约定，安全复核后再上线；不要接入个人文库及个人密钥。
